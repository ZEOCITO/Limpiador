# Limpiador🧹✨

Aplicación para Windows que analiza el equipo y ayuda a eliminar archivos para que recuperes espacio en tu disco.

## Funciones

- Limpia archivos temporales, cachés e informes de errores antiguos.
- Permite vaciar la papelera y revisar carpetas vacías o restos de aplicaciones.
- Permite seleccionar individualmente archivos personales sin abrir durante 1 año o más.

## Instalación

Descarga **Instalador Limpiador v1.1.exe** desde **El Repositorio**. La instalación propone `C:\Program Files (x86)\Limpiador`, pero puedes cambiar la ruta con **Examinar**.

**Importante:** revisa los archivos seleccionados antes de confirmar. La eliminación es permanente y la fecha de último acceso de Windows puede ser imprecisa.
